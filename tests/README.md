# tests/ — pruebas automáticas

Se corren con `npm test` (node:test, sin librerías extra).

- `engine.test.js`: misma semilla = mismo resultado, nunca se vacuna a un caso reportado, el presupuesto no se pasa, la otra ciudad funciona, etc.
- `lambda.test.js`: la API valida los datos y responde lo mismo que el navegador.
