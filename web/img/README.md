# web/img/ — imágenes y video

| Carpeta o archivo | Qué es |
|---|---|
| `historia/` | Las 8 escenas de la película del principio (generadas con Higgsfield). |
| `carga/` | La escena de carga de cada brote: el zombi, el bus de la gripe, el mosquito del dengue y la calle de barrio con tanques de agua (Higgsfield). |
| `barrio/` | Las piezas del barrio: casas, colegio, iglesia, trabajos, contenedores, pangas, palmeras y restos. `sprites.json` dice dónde apoya cada pieza en el suelo. |
| `suelo/` | Texturas del suelo del barrio: asfalto, arena, mar, tierra, vereda y suelo seco. |
| `ilustraciones/` | Imágenes de los escenarios, del Brote Sorpresa y de cada parroquia (dos son fotos reales de Wikimedia Commons). |
| `zombi.mp4` | El zombi que se traga la pantalla al pulsar "Calcular". |
| `manta-satelite.jpg` | Imagen satelital de Manta para "La ciudad". |
| `guayaquil-satelite.jpg` | La de Guayaquil, que el motor también sabe simular. |

Autores y licencias: `docs/creditos.md`.
